# Wedding Dashboard - Cherry & Cream Theme

Dashboard Admin Web Undangan Pernikahan yang dirancang dengan estetika warna **Cherry & Cream**.

## Structure Folder:
- `index.html` : File utama HTML Dashboard.
- `css/styles.css` : File stylesheet tema Cherry & Cream.
- `js/script.js` : Logika interaktif (RSVP, QR Generator, Pemutar Musik, Edit Nama).
- `audio/` : Folder tempat penyimpanan file musik/lagu latar.

## Cara Penggunaan:
1. Ekstrak file zip ini.
2. Buka file `index.html` pada web browser Anda.
